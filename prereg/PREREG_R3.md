依据：按总账能量粗算，只用 k 遍当个人参照时，噪声约为 s²(1 + 1/k)；用示范均值当参照时，噪声约为 s² + 2V_s。EC3D 位置尺子上，m²/s² 深蹲约 4.2、弓步约 1.8。所以深蹲少数几遍即可回收，弓步需要更多遍。

适用格（ΔAUC ≥ 0.05，共 7 格）：
- EC3D 位置：深蹲、弓步
- EC3D 27 对骨夹角：深蹲、弓步、平板
- GAITEX：rd、rgs

H11：7 格中，k = 1 的合并 AUC（50 次均值）都高于 D2 的合并 AUC。7 格全满足判"支持"，4–6 格满足判"部分支持"，否则判"不支持"。
H12：7 格中，合并 AUC 随 k = 1、2、3、5 不下降（相邻两档的下降不超过 0.01）。判法同 H11。
H13：EC3D 位置尺子的深蹲，k = 1 的回收比例 ≥ 0.5。
H14：EC3D 位置尺子上，弓步的 k*(0.8) 不少于深蹲的 k*(0.8)。
H15：GAITEX 的 rd 和 rgs 中，k = 3 时，平均检出率低于 0.1 的新人不超过 1 名，且平均误报率高于 0.5 的新人不超过 1 名（平均指 50 次重复的均值）。两个子集都满足判"支持"，只有一个满足判"部分支持"。

【K1 个人校准曲线（H11–H15）】
1. 自检：用本轮代码重算 O 和 D2 的合并 AUC，必须与前两轮的落盘值逐项相同（最大绝对差 < 1e-9）。对照来源：EC3D 位置用 exp/prl_v2/e1，27 对骨夹角用 round2/r2，GAITEX 用 round2/r4。
2. 计算：对每个 数据集 × 动作 × 尺子 × k，每次重复都用留一人方式，算出：
   - 每名新人的实际误报率、检出率、人内 AUC；
   - 全部新人拼起来的合并 AUC。
3. 汇总 50 次：
   - 合并 AUC 的均值，以及 2.5%、97.5% 分位；
   - 回收比例的均值和分位；
   - k*(0.5)、k*(0.8)；
   - 每名新人误报率、检出率的 50 次均值。
4. 按 H11–H15 判定。
文件：pooled.csv、recovery.csv、per_person.csv、prereg_check.json、selfcheck.json。逐次分数只存每次重复的汇总即可，不必逐行全存。

【K2 挑最像的示范者（可选，只描述）】
目的：不找老师确认，而是从一群示范者里挑一个和新人最像的人当参照，看这样能不能代替个人校准。
1. 候选示范：其余每人在位置空间的 medoid 正确重复（与 D1 相同）。
2. 两种挑法，都在被评估的那把尺子里挑：
   - S-all：用新人的全部重复（不看标签），挑使"新人各重复到该示范的分数中位数"最小的示范者。这是现实里的做法，会受新人错误动作的影响。
   - S-cor：只用新人的正确重复去挑。这是上限：挑选时用了标签，但参照本身仍是别人的动作。
3. 阈值：校准人 c 用同样的挑法，从不含 c、也不含 h 的人里挑示范者，再用 c 的正确重复定 τ。
4. 报告：每名新人挑中的是谁、合并 AUC、每人的误报率与检出率、人内 AUC < 0.5 的个数。与 O、D2、P1、P3 并列。
