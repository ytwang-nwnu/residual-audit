# PREREG_R7 学习式检测器的留一人审计

写于 2026-11-02，运行之前。编号 R7 与 H16–H19 为暂定，若服务器上已被占用则顺延，其余文字不动。

## 目的

检验第 3 节的机理是否只对距离加阈值的参照驱动打分器成立。把三个带官方代码的学习式检错方法当作审计对象，在 EC3D 上用留一人划分复现"示范参照"的处境，再用个人校准（从输入中减去学员本人的稳定个体项）看损失能否收回。本轮不比较方法优劣，不调超参，不追数字。

## 依据

总账已落盘的位置空间 ρ：深蹲 2.08，弓步 0.7982，平板 0.07456。
e1 位置空间 D2 的 ΔAUC：深蹲 0.262，弓步 0.114，平板 0.019。
预期：学习式模型在留一人下看到的被留学员带着 s_h，与 D2 下学员带着 s_i − e_r 是同一处境，所以损失应当存在、排序应当随 ρ、减去 s_h 后应当收回。

## 共用设定

- 数据：EC3D，与 e1 同一批 371 段（错误 251，正确 120；9 段标签未知的深蹲按错误计）。段的切分与标签来自 prl_scheme12.py / ec3d_common.py 的读取，不重新切分。M1 多分类头用 pickle 自带的细类标签，二值化一律按"非该动作正确类即错误"。
- 输入：每段 19 关节三维坐标，逐帧减关节 8，线性重采样到 T = 100 帧。不做 DTW 对齐，不旋转摆正。各方法自带的归一化在此之后照常执行。邻接由 ec3d_common.BONES 的 23 对骨生成。
- 训练配方：模型、损失、优化器、轮数、DCT 等按各自仓库默认；只改数据划分与输入。不按测试表现挑 checkpoint，取最后一轮。
- 分数：每条重复一个错误分数。M1 取 1 − p(该动作正确类)，p 在该动作的各类内归一；M2 以错误 = 1、正确 = 0 为回归目标，分数取输出；M3 取 p(错误)。
- 三种划分：
  - S0 原划分：只对 M1，按仓库自带划分训练与测试，并记录测试集学员是否同时出现在训练集。只描述。
  - S1 留一人（对应示范参照）：每折以 3 人全部重复训练，被留学员全部重复测试。4 折。
  - S2 留一人加个人校准（对应 P_k 与 O）：训练学员每条重复逐帧减去本人同动作全部正确重复的均值，再加回全体训练学员正确重复的总均值；被留学员用 k 条本人同动作正确重复的均值做同样的减法，加回的总均值仍用训练学员的。k ∈ {1, 2, 4}，每个 k 抽 20 次，抽中的 k 条不进该次测试集。k = 全部记作 S2-all：正确重复用本人其余正确重复的均值（留一），错误重复用本人全部正确重复的均值。S2 的训练每折只做一次，k 只影响测试时的校准。
- 随机数：训练 seed ∈ {0, 1, 2}；抽取用 numpy default_rng(seed)，抽取序列对三个方法相同。
- 指标：
  - 人内 AUC：被留学员某动作的错误分数对正确分数做 Mann–Whitney，平手记 0.5。
  - 合并 AUC：4 名被留学员的分数拼起来算，同一 seed 下 4 折各用自己的模型。
  - ΔAUC_L = S2-all 合并 AUC − S1 合并 AUC，按 3 个 seed 取均值。
  - 回收比例(k) = (S2-k 合并 AUC − S1 合并 AUC) ÷ (S2-all 合并 AUC − S1 合并 AUC)，分子分母都在同一次抽取的测试子集上算，S1 与 S2-all 的分数不变只取子集；先对 20 次抽取取均值再对 seed 取均值。k*(0.8) 为回收比例首次 ≥ 0.8 的最小 k，4 以内达不到记 ">4"。
  - 工作点：各方法自带的判决（argmax 或 0.5），记每名被留学员的误报率与检出率。退化对照：被留学员正确重复在 S1 下的报警率即误报率，单列一行。

## 预测与判法

- H16（学习式检测器同样有示范参照损失）：每个方法在 3 个动作中至少一个动作 ΔAUC_L ≥ 0.05。3 个方法都满足判"支持"，2 个满足判"部分支持"，否则判"不支持"。
- H17（损失排序与 ρ 一致）：每个方法的 ΔAUC_L 以深蹲最大、平板最小。判法同 H16。
- H18（个人校准可收回损失）：每个方法在 ΔAUC_L ≥ 0.05 的动作上，k = 2 的回收比例都 ≥ 0.5。判法同 H16。
- H19（失效落在人上而非阈值上）：S1 工作点下，每个方法至少一个动作的 4 名被留学员检出率极差 ≥ 0.3，且该动作在 S2-all 下极差缩小。判法同 H16。

只描述、不判定：S0 与 S1 的差及学员是否混入；k = 1、4 的回收比例；每名被留学员的误报率、检出率；人内 AUC。

退出规则：某方法在 S2-all 下三个动作合并 AUC 均 < 0.6，视为无法从 3 人学到判别，该方法退出 H17、H18、H19 的判定，H16 仍计入，原因记入 MANIFEST。

预算：先以 M1 S1 第 0 折 seed 0 做 pilot 实测单 run 时间与显存。三方法合计预计超过 24 GPU 小时则 seed 减为 1 并记录。
